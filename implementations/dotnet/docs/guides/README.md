Si estás empezando desde cero, usa primero [`../../START_HERE.md`](../../START_HERE.md).

|---|---|
| [`MinimalExample.md`](MinimalExample.md) | quieras entender primero “Application coordina → Domain decide” sin cargar todavía todo el hexágono |

| [`GuidedTours.md`](GuidedTours.md) | quieras seguir CraftItem, GetInventory y ProcessFoodSpoilage archivo por archivo |
| [`AntiPatterns.md`](AntiPatterns.md) | quieras reconocer errores de fronteras y dependencias |
| [`Exercises.md`](Exercises.md) | quieras practicar con cambios pequeños como RepairItem |
| [`RunAndValidate.md`](RunAndValidate.md) | quieras compilar, ejecutar tests, migrations, Hosts y preparar un release |
| [`SQLiteDemo.md`](SQLiteDemo.md) | quieras comprobar persistencia real entre reinicios |
| [`Visualizer.md`](Visualizer.md) | quieras aprender progresivamente con Execution Flow y Repository Map |
